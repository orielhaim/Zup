Documentation
=============

Installed by the "Documentation" component. Deselect that component in the
installer window and these files are not written at all, which is the point of
tagging them with a component.

Exercising the flows
--------------------

  Install      the default surface; pick a scope, pick components, press Install
  Modify       press Change to re-open the component choices on an installation
               that already exists
  Repair       delete a file from the install directory, then press Repair; the
               file comes back because Repair restores what drifted
  Uninstall    press Uninstall, then confirm; everything goes, including the
               PATH entry and the shortcuts

To find the install directory, press "Show what will change" in the window, or
look at the Location line.
