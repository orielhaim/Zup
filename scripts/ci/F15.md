# F15 Windows privileged coverage

Run `python scripts/ci/verify_windows_privileged.py` on native Windows. CI uses
this command without UAC interaction. A non-elevated process fails the job with
an explicit coverage-unavailable diagnostic. Administrator group membership is
not sufficient: GetTokenInformation(TokenElevation) checks the process token.

`windows-privileged-tests.json` records all 45 ignored IDs from native nextest
JSON discovery at F14, including binary identity, category, features and
privilege requirements. The required set contains nine filesystem tests, five
machine-authority tests and one recovery test. All features are enabled.
The journal creation crash matrix and its child require test-faults. Native SCM
cases require test-launcher and remain under verify-windows-services.ps1 and
its isolated-runner requirements. Disposable-VM ledger, prerequisite and real
profile cases are inventoried but excluded from this required suite.

The stale filter selected six required tests and omitted nine filesystem tests.
Its machine_runtime_ arm still matches the recovery test. The checked-in stale
JSON fixture contains actual ignored discovery records, not inferred names.
Discovery compares every ignored ID across the package with the reviewed
inventory, then requires exact equality between selected and required IDs.
New ignored tests, module moves, removals, changed ignore status and feature
loss require explicit policy review. Counts alone cannot satisfy the gate.

Execution removes stale JUnit output, preserves nextest's exit status, rejects
zero tests, and checks that each required ID has exactly one passing record.
Skipped, missing, duplicate and failing records fail the gate. CI uploads JSON
and JUnit evidence even on failure. The general fast suite is unchanged.

Local validation on 2026-11-13: native all-feature and default-feature discovery;
stale-filter reproduction; five Python guard/reporter tests; YAML parse;
cargo fmt --all --check; focused all-feature/all-target Clippy; 152 non-ignored
zup-windows library tests passed. A harmless library test validated the actual
nextest JUnit schema. The exact privileged command failed at TokenElevation
(false), before mutations: none of the 15 privileged tests ran here. Native
ACL/publication/namespace/lock/journal/restricted-token execution and hosted CI
remain unverified. CI must fail if its runner cannot supply an elevated token.
No host/VM provisioning or SCM mutations were performed.

F14's fault-enabled staging crash-fixture gap remains open. This change neither
excludes it from the general suite nor claims that it passed.
